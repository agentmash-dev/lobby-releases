# agentmash lobby

downloads for the agentmash lobby desktop app: your coding agents side by side on your own logins, your team's sessions next to yours, and a way to ask a teammate's agent for something that they approve first. the download page is [agentmash.dev/download](https://agentmash.dev/download).

this repository holds release builds only. the source is private.

## closed beta

agentmash is in a closed beta while we finish it. the app only signs in people we've invited, so there's nothing here for you to download yet. request early access at [agentmash.dev](https://agentmash.dev/#request): tell us who you are and what you build, and we'll write when your spot opens.

if you're already in, the app updates itself.
